# TimeStopper
TimeStopper — desktop-приложение для Windows, предназначенное для контроля времени, проводимого пользователем в различных приложениях на компьютере.

Проект разрабатывается на Python. Его основная идея — помочь пользователю осознанно управлять своим временем с помощью отслеживания активности, дневных лимитов и игровой системы мотивации.

## Основные возможности

Планируемый функционал:

  - Отслеживание активного окна Windows.
  - Определение используемого приложения.
  - Подсчёт времени использования каждого приложения.
  - Настройка индивидуальных дневных лимитов.
  - Начисление баллов за соблюдение лимитов.
  - Списание баллов за превышение ограничений.
  - Просмотр статистики использования.
  - Система достижений и наград.
  - Уведомления о приближении к установленному лимиту.

## Принцип работы отслеживания

TimeStopper определяет активное окно операционной системы Windows и получает информацию о соответствующем процессе.

## Например:
- Пользователь работает в Google Chrome — время записывается для chrome.exe.
- Пользователь переключается на Discord — учёт времени Chrome прекращается, начинается учёт Discord.
- Пользователь бездействует — учёт времени приостанавливается после установленного периода.
- Собранные данные сохраняются в SQLite и используются для формирования статистики.

## Система баллов
В приложении планируется игровая система мотивации.
## Пример правил:
- Соблюдение дневного лимита: +20 баллов.
- Превышение дневного лимита: −30 баллов.
- Накопленные баллы можно будет обменивать на награды.
Значения будут настраиваться в процессе разработки.
